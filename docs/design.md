# Visual direction

A campus study notebook: a calm white workspace, forest-green identity, indigo pen annotations and one oversized orbital sketch. Avoid invented student stats and mock schedules.

Tokens: paper #f7faf8; white #ffffff; forest #124e3b; ink #18342b; secondary #52665d; orange #a23b14; line #d1dfd7. Typography: locally available Trebuchet MS for friendly headings; Segoe UI/Arial body. No external font request or dependency. Spacing: 4,8,12,16,24,32,48,64,96px; 8px input radius, 20px illustration container; focus 3px forest outline. Motion only on user feedback, respects reduced motion.

Layout: left-aligned hero with generous sentence measure, right abstract orbital illustration; sequential weekly-loop section below. Mobile stacks naturally and preserves 44px controls. Later authenticated surfaces should emphasize the next session and pending decisions. Status text stays explicit while unfinished authentication is unavailable; never use fake sign-in controls.

Review: the notebook concept is grounded in the recurring student study loop, not a dashboard full of fabricated metrics. The orbit is the sole decorative element. Content is semantic text, not rendered inside images.
